# ZARWA Launcher 🚗

لانشر أندرويد بريميوم (ستايل BMW / Mercedes) لشاشة العربية.
معمول مخصوص لوحدتك: **Android 14 · T100/A100 · 1280×720 · 2GB RAM**.

<a name="features"></a>
## 1) اللانشر بيعمل إيه
واجهة بريميوم بستايل MBUX / BMW iDrive، **صفحتين تسحب بينهم** + زرار تبديل **داكن/فاتح**:

**صفحة 1 — الداشبورد (ويدجتس):**
- ساعة كبيرة + تاريخ عربي.
- **ويدجت طقس حقيقي** (من الإنترنت، من غير مفتاح API — افتراضياً القاهرة، يتغيّر).
- **مشغّل ميديا غني**: صورة الألبوم + اسم الأغنية + شريط تقدّم + أزرار — بياخد من أي مشغّل شغّال فعلاً.
- **كارت ملاحة** بيفتح الخرائط.
- ويدجتس **التكييف / المدى / حالة العربية** (شكل دلوقتي — محتاجة ربط CAN عشان الأرقام الحقيقية).
- **دوك تطبيقات** تحت: هاتف · خرائط · فيديو · راديو · كاميرا · إعدادات · تطبيقات.

**صفحة 2 — كل التطبيقات:** بحث + كل التطبيقات المتسطّبة.

- كل زرار بيجرّب أكتر من طريقة عشان يفتح التطبيق الصح، ولو ملقاش بيفتحلك قائمة التطبيقات.
- بيدعم التنقّل بأزرار الدركسيون (DPAD) — العنصر المختار بيتحدّد بإطار أزرق.

### أول تشغيل (خطوة واحدة اختيارية)
عشان ويدجت الميديا يقرأ الأغنية والصورة: اضغط على زرار التشغيل مرة → هيفتحلك إعدادات **Notification access** → فعّل **ZARWA**. (من غيرها الأزرار برضه بتشتغل، بس مش هيبان اسم الأغنية.)

<a name="build"></a>
## 2) طلّع الـ APK بدون تسطيب أي برامج (البناء في السحابة)
دي أسهل طريقة ليك لأنك مش محتاج تسطّب Android Studio ولا حاجة.

1. اعمل حساب مجاني على [github.com](https://github.com) لو معندكش.
2. اعمل **New repository** (اسمه مثلاً `zarwa-launcher`) — خليه Public.
3. ارفع كل ملفات الفولدر ده جواه (زرار **Add file → Upload files** واسحب الملفات كلها).
4. أول ما ترفع، هيشتغل البناء لوحده. روح تاب **Actions** في الريبو.
5. استنى لما العملية تخلص (علامة ✔ خضرا، حوالي ٣-٥ دقايق).
6. افتح آخر Run → تحت **Artifacts** هتلاقي `ZarwaLauncher-debug-apk` → نزّله.
7. جواه ملف `app-debug.apk` → ده اللانشر بتاعك ✅

> لو عايز أساعدك في الرفع خطوة بخطوة قولي.

**بديل (لو عندك كمبيوتر وعايز تبني بنفسك):** افتح الفولدر بـ Android Studio → استنى المزامنة → `Build > Build APK`.

<a name="install"></a>
## 3) ركّب الـ APK على الشاشة
**الطريقة الأسهل — فلاشة USB:**
1. انسخ `app-debug.apk` على فلاشة.
2. حطها في الشاشة، افتح مدير الملفات (File Manager) واضغط على الملف.
3. لو طلبت "Unknown sources" وافق (Settings → Security → Allow).
4. اضغط Install.

**الطريقة الاحترافية — ADB من الكمبيوتر:**
```bash
adb install -r app-debug.apk
```

<a name="default"></a>
## 4) خليه اللانشر الافتراضي
**عادي:** اضغط زرار Home في الشاشة → المفروض يسألك تختار لانشر → اختار **ZARWA** واضغط **Always**.

**لو الشاشة مقفولة ومش بتديك الاختيار** (شائع في الوحدات الصينية) — استخدم ADB:
```bash
# اعرف اسم اللانشر الأصلي (اختياري)
adb shell cmd package resolve-activity -c android.intent.category.HOME

# خلي ZARWA هو الافتراضي
adb shell cmd package set-home-activity com.zarwa.launcher/.MainActivity
```
لو الأمر ده مرفوض، جرّب:
```bash
adb shell pm disable-user --user 0 <package-اللانشر-الأصلي>
```
> ⚠️ متعملش disable للانشر الأصلي غير لما تتأكد إن ZARWA شغّال، عشان متبقاش من غير شاشة رئيسية.
> للرجوع: `adb shell pm enable <package-اللانشر-الأصلي>`

<a name="swc"></a>
## 5) أزرار الدركسيون (Steering Wheel)
- أزرار الميديا (تشغيل/التالي/الصوت) بتشتغل تلقائيًا لأن النظام بيبعتها كـ media keys واللانشر بيمرّرها للمشغّل.
- أزرار الحركة (فوق/تحت/OK) بتنقّلك بين المربعات وبتفتح المختار.
- عايز تعرف كل زرار بيبعت إيه بالظبط؟ وصّل الشاشة بـ ADB وشغّل:
  ```bash
  adb shell getevent -l
  ```
  اضغط الأزرار وابعتلي اللي يطلع، وأنا أربط كل زرار بالوظيفة اللي إنت عايزها.

<a name="customize"></a>
## 6) عايز تغيّر حاجة؟
- **المربعات وترتيبها:** في `MainActivity.kt` داخل دالة `setupFavorites()`.
- **إيه اللي كل زرار بيفتحه:** في `AppLauncher.kt` (لو عرفنا أسماء باكدجات تطبيقات وحدتك بالظبط بنخليها تفتح على طول من غير تجربة).
- **الألوان والثيم:** `res/values/colors.xml`.
- **الخلفية:** `res/drawable/bg_gradient.xml`.
- **حجم/شكل المربعات:** `res/layout/item_tile.xml`.
