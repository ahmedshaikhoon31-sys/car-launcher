1 إيه هو ZARWA Launcher؟

هو الواجهة الرئيسية لشاشة عربيتك — بيقعد فوق نظام الأندرويد الموجود (مش بيستبدله)، فأي غلطة ترجع للانشر الأصلي بأمان. بيديك تحكّم كامل في الشكل والتقسيم والثيمات، وبيفتح كل التطبيقات.

المميزات

  • صفحتين تسحب بينهم + زرار تبديل داكن / فاتح.
  • ساعة كبيرة + تاريخ عربي + ويدجت طقس حقيقي (من الإنترنت).
  • مشغّل ميديا غني: صورة الأغنية + الاسم + شريط تقدّم + أزرار.
  • كارت ملاحة + دوك تطبيقات (هاتف · خرائط · فيديو · راديو · كاميرا · إعدادات).
  • قائمة كل التطبيقات مع بحث.

2 تحميل الـ APK من GitHub

الـ APK بيتبني في السحابة أول ما ترفع أي تعديل — إنت مش محتاج تسطّب أي برنامج.

  1. افتح صفحة الريبو بتاعك على GitHub → تاب Actions.
  2. اضغط على آخر بناء عليه علامة ✅ خضرا.
  3. انزل لآخر الصفحة لقسم Artifacts.
  4. اضغط على ZarwaLauncher-debug-apk → هينزل ملف zip.
  5. فك الضغط (Extract) → جواه app-debug.apk ← ده اللانشر.
💡 كل ما تعدّل أي حاجة وترفعها (Push)، بيتعمل APK جديد تلقائياً في دقايق.

3 تركيبه على الشاشة

الطريقة الأسهل — فلاشة USB

  1. انسخ app-debug.apk على فلاشة.
  2. حطها في الشاشة، افتح File Manager واضغط على الملف.
  3. لو طلب Unknown sources → وافق (Settings → Security → Allow).
  4. اضغط Install ← بعدها Open.

الطريقة الاحترافية — ADB

adb install -r app-debug.apk

4 التجربة الأولى

⚠️ مهم: أول مرة جرّبه كتطبيق عادي — متخليهوش الافتراضي لحد ما تتأكد إنه شغّال كويس عندك.

افتحه وجرّب: الساعة، الطقس، زرار الداكن/الفاتح، اسحب للصفحة التانية (كل التطبيقات)، اضغط على الأيقونات وشوفها بتفتح صح.

5 تخليه اللانشر الافتراضي

الطريقة العادية

اضغط زرار Home في الشاشة → المفروض يسألك تختار لانشر → اختار ZARWA واضغط Always / دائماً.

لو الشاشة مقفولة ومش بتديك الاختيار (شائع في الوحدات الصينية)

استخدم ADB من الكمبيوتر:

adb shell cmd package set-home-activity com.zarwa.launcher/.MainActivity
🛑 متعملش disable للانشر الأصلي غير لما تتأكد إن ZARWA شغّال، عشان متبقاش من غير شاشة رئيسية. للرجوع في أي وقت: 
adb shell cmd package set-home-activity <package-اللانشر-الأصلي>

7 أزرار الدركسيون

  • أزرار الميديا (تشغيل / تالي / صوت): بتشتغل تلقائياً — اللانشر بيمرّرها للمشغّل.
  • أزرار الحركة (فوق / تحت / OK): بتنقّلك بين العناصر وبتفتح المختار (بيتحدّد بإطار أزرق).

عايز تعرف كل زرار بيبعت إيه بالظبط عشان نبرمجه؟ وصّل الشاشة بـ ADB وشغّل:

adb shell getevent -l

اضغط الأزرار، وابعت اللي يظهر، ونربط كل زرار بالوظيفة اللي إنت عايزها.

8 تفعيل قراءة الموسيقى

عشان ويدجت الميديا يبيّن اسم الأغنية وصورتها:

  1. في اللانشر، اضغط على زرار التشغيل في كارت الميديا مرة.
  2. هيفتحلك إعدادات Notification access.
  3. فعّل ZARWA من القائمة.
من غير الخطوة دي الأزرار برضه بتشتغل، بس مش هيبان اسم الأغنية والصورة.

9 ADB — يعني إيه وإزاي تستخدمه

ADB = جسر بين الكمبيوتر والأندرويد. بتوصّل الشاشة بالكمبيوتر وتتحكم فيها بأوامر بسيطة.

التسطيب (مرة واحدة)

  1. نزّل Platform Tools من موقع أندرويد الرسمي (ابحث: "SDK Platform Tools").
  2. فك الضغط في فولدر على الكمبيوتر (مثلاً C:\adb).
  3. في الشاشة: فعّل Developer Options ثم USB Debugging.
  4. وصّل الشاشة بالكمبيوتر بكابل USB، أو استخدم ADB واي فاي لو الوحدة بتدعمه.
  5. افتح موجّه الأوامر في فولدر adb واكتب adb devices — المفروض تظهر الشاشة.
مش لازم دلوقتي — اللانشر بيشتغل من غيره. بس مفيد لو حبينا نظبط الافتراضي أو الأزرار أو الـ CAN.
